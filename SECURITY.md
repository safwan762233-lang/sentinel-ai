# Security Policy

## Scope
This repository is an early-stage Android security utility. It is not yet suitable for enterprise deployment or as a replacement for a reputable endpoint security product.

## Reporting a vulnerability
Do not publish exploit details or personal data in a public issue. Contact the repository owner privately through GitHub's security advisory reporting feature, if enabled.

## Safe-use principles
- Never upload user files or app inventories without clear consent.
- Never delete or modify files automatically.
- Treat heuristic alerts as unverified indicators.
- Keep audit records free of secrets and personal content.
- Review all third-party dependencies, licenses, and update provenance before release.
